≈≈# C 행맨(HangMan) 게임
C언어로 만든 콘솔 행맨 게임입니다. 2026학년도 2학기 C프로그래밍 기말 프로젝트입니다.
1. 프로젝트 소개 및 주제 선정 이유
소개숨겨진 영어 단어의 알파벳을 하나씩 추측해 맞히는 게임입니다. 한 판을 성공하면 다음 판이 자동으로 이어지임입니다. 한 판을 성공하면 다음 판이 자동으로 이어지고,
실패하면 그때까지 성공한 판 수와 점수를 출력합니다 이후 계속할지 묻고, 'y'를 입력하면 처음부터 다시 시작합니다.
주제 선정 이유
수업에서 배운 문자열, 배열, 반복문, 함수, 파일 입출력을 하나의 프로그램에 모두 적용해 볼 수 있는 주제라서 선택했습니다.규칙이 단순해서 핵심 로직을 정확히 이해하고 구현할 수 있습니다. 그래서 난이도가 낮은
대신 점수정책,입력 예외 처리, 코드 구조, 문서화의 완성도를 높이는 데 집중하려 합니다.
2. 관련 연구
행맨 게임의 규칙
출제자가 단어를 정하고 글자 수만큼 빈칸(`_`)을 보여줍니다.
플레이어는 알파벳을 한 글자씩 말합니다.
단어에 있는 글자면 해당 위치가 공개되고, 없으면 오답 횟수가 늘면서 그림이 한 부분씩 완성됩니다
오답이 정해진 횟수에 도달하기 전에 단어를 모두 맞히면 승리합니다.
구현에 필요한 C 기술 조사
필요 기능,사용 기술
단어 목록 읽기: (fopen,fgets,fclose) (파일 입출력) 파일 입출력을 왜 적어냐면 fopen, fgets, fclose가 어떤 기능 그룹에 속하는 함수들인지 한눈에 알아보기 위해 적었습니다.
무작위  단어 선택: ( srand, rand, time) (함수 역할: 난수 생성 — 매 판 다른 단어를 무작위로 고르기 위함)
문자처리: (ctype.h tolower, isalpha) (대소문자 통일 및 알파벳 여부 검사 — 입력 오류 방지 및 판정 일관성을 위함)
